## About

I build robotic, embedded, and sensing systems, from PCB design and sensor integration to mechanical CAD and software. My current focus is robot manipulation and embodied intelligence, and I am working on ROS 2 simulation experiments to build the control and robotics foundations that work requires.

## Focus Areas

| Area | What I work with |
|:---|:---|
| **Robotics** | ROS 2, URDF and simulation, teleoperation with OpenCV and MediaPipe |
| **Electronics & Embedded** | KiCad PCB design, RP2040, ESP32-C3, I²C, SPI, sensor integration |
| **Mechanical Design** | SolidWorks assemblies and mechanisms, 3D-printed enclosures |
| **Software** | Python, C++, TypeScript |
